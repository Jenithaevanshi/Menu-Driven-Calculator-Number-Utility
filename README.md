# Menu-Driven-Calculator-Number-Utility
A beginner Python project that combines calculator operations and number-checking utilities in a simple menu-driven program.

## Features
- Addition, subtraction, multiplication, and division
- Percentage calculation
- Even/odd checking
- Compare two numbers
- Handles invalid numeric input and division by zero
- Runs repeatedly until the user exits

## Concepts used
Variables, functions, input/output, conditionals, loops, dictionaries, and exception handling.
